# Introduction to R and RStudio

An optional introductory course for Master's students in Health Sciences who would like supported practice with R before Basic Research Methods.
No previous programming experience is required.

The course consists of two sessions, each with three 45-minute blocks.
Short demonstrations alternate with independent exercises using health-science examples.

## Course materials

- [Day 1: Getting started with R](https://jsepin.github.io/introduction-to-r-rstudio/RStudio_Day1_Course.html)  
  Scripts, objects, functions, vectors, missing values, data frames, and importing and exporting CSV files.

- [Day 2: Transforming and visualising data](https://jsepin.github.io/introduction-to-r-rstudio/RStudio_Day2_Course.html)  
  Selecting and filtering data, creating variables, summarising groups, and making plots.

## Before the course

Install [R](https://cran.r-project.org/) and then [RStudio Desktop](https://posit.co/download/rstudio-desktop/).
Bring your laptop and charger.

## Working through the exercises

Write your code in an R script.
Start with the core tasks, use the hints when needed, and check the solutions after your attempt.
Extensions and additional practice are optional.
